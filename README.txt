SPARFUCHS MOBIL 1.0 – TESTVERSION

1. Alle Dateien gemeinsam auf einen HTTPS-Webserver (z.B. GitHub Pages) hochladen.
2. Auf Android in Chrome öffnen, Menü > Zum Startbildschirm hinzufügen / App installieren.
3. Bon fotografieren, optional OCR starten (Internet erforderlich), Positionen prüfen, Bonsumme abgleichen, speichern.
4. Regelmäßig JSON-Sicherung und CSV für Excel exportieren.

WICHTIG: Keine Google-Drive-Synchronisierung; keine automatische Übernahme in Excel.
OCR benötigt Internet für Bibliothek/Sprachmodell und kann Fehler machen.
Lokale Daten liegen nur im Browserprofil des Geräts.
Das Öffnen der index.html als file:// ist kein installierbarer PWA-Betrieb.
